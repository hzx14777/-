2. 统一登录流程（规范 §7.2）

授权码模式（平台不自建账号密码）

  1. 用户访问 /yj/login，本地无有效会话
  2. 跳转认证中心 /sso/oauth/authorize?client_id=exam-platform-client&redirect_uri=…/yj/sso/callback&state=…
  3. 认证中心完成登录，302 回调 /yj/sso/callback?code=…&state=…
  4. 前端把 code 交回服务端 POST /api/v1/sso/exchange，服务端换取令牌，前端不保存长期凭证
  5. 服务端读取统一用户信息，建立 2 小时本地会话（Refresh Token 7 天，轮换）
  6. 退出时清理本地会话并按 endSessionUrl 退出认证中心

统一用户信息字段（§7.3，不得改名）

4. 接口契约（规范 §10）

成功 / 失败响应

// 成功
{
  "code": "OK",
  "message": "success",
  "data": { "exams": [] },

5. 业务事件与跨平台联动（规范 §11）

本平台生产的事件

{
  "eventId": "evt_mw1bxvtd2352",
  "eventType": "exam.passed",
  "occurredAt": "2026-11-04T07:39:27+08:00",
  "sourcePlatform": "exam",
  "operatorId": "u_tch",
  "data": {
    "attemptId": "att_…", "examId": "e_dp_admission",
    "examType": "admission_exam", "userId": "u_stu1",
    "totalScore": 78.5, "dualPass": true,
    "admissionId": "adm_…"
  }
}
出站留痕：status / attempts / lastAt / lastError / payloadDigest，可在「审计与事件」页人工重放（§11.4）。

消费的事件

{
  "eventId": "evt_course_001",
  "eventType": "course.completed",
  "occurredAt": "2026-11-04T07:00:00+08:00",
  "sourcePlatform": "selfstudy",
  "operatorId": "u_stu1",
  "data": { "userId": "u_stu1", "chapterId": "ch_ns_2" }
}
联动方向
自学完成 → 解锁章节考试入站 course.completed
考试通过 → 工坊准入判断出站 exam.passed + 公开查询
个人成长档案按统一 userId 汇总记录
入站接口对相同 eventId 返回 duplicate: true，不重复产生业务结果。
