重启后打不开的根因

根因证据
16 个进程从未注册为系统服务 / 启动项 服务、计划任务、启动文件夹、注册表 Run 键中均无相关项
进程随宿主会话退出被整体回收 启动命令返回后数分钟内进程全部消失，日志无 Shutting down
SERVER__PORT 覆盖服务端口 Nacos 实际起在 59089，因端口占用直接启动失败
JAVA_HOME 未持久化 系统与用户环境变量查询均为空，全靠硬编码路径

已修复：统一控制脚本 ykctl.ps1（端口探针 + 幂等 + 环境净化）、启动文件夹自启（由 explorer 托管，脱离会话 Job）、持久化 JAVA_HOME。

日常操作

start-all.bat # 全量启动，约 5-7 分钟 status.bat # 查看 18 个监听点 stop-all.bat # 全量停止

位于 桌面\考试平台2\oss-run\

# 只起某一层 ykctl.ps1 start infra # 库/缓存/注册中心 ykctl.ps1 start core # 核心四服务 ykctl.ps1 start exam # 考试业务十服务 ykctl.ps1 start front # 前端

位于 C:\yk-runtime\ykctl.ps1

重要约束

Nacos 必须先于微服务就绪；中途重启 Nacos 会使已连接的 Dubbo 客户端失联，登录将返回「RPC异常」。若单独重启过 Nacos，须连带重启全部微服务。
